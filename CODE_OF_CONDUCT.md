# Code of Conduct

## Our standard

We are committed to a welcoming, respectful, and security-conscious community. Participate constructively, assume good intent, and keep discussions focused on improving the project.

## Expected behavior

- Be respectful and precise.
- Welcome different experience levels and viewpoints.
- Protect private data and never post real credentials.
- Report security vulnerabilities privately using `SECURITY.md`.
- Accept technical feedback without personal attacks.

## Unacceptable behavior

- Harassment, discrimination, threats, or doxxing.
- Publishing secrets, private data, or exploit details against live systems.
- Deliberate disruption, spam, or impersonation.

Project maintainers may remove content or restrict participation when necessary to protect the community and the project.
